# Hvordan deler jeg dokumenter?

## Formål

Del et Google-dokument med en person uden for Ishøj Kommune eller uden @meddel.dk-konto.

## Hvornår skal jeg bruge denne guide?

Brug den, når standarddelingen i Google Drev er for begrænset, og en ekstern modtager skal kunne læse eller redigere dokumentet.

I Ishøj Kommune er Google Drev sat op således, at deling af dokumenter som standard foregår iblandt andre i kommunen og dem, der ellers er tilknyttet en **meddel.dk**-konto.

Men man kan sagtens dele dokumenter med udefrakommende alligevel. Det kræver bare lidt ekstra trykkeri, når man skal dele sit dokument.

## Trin-for-trin

{% stepper %}
{% step %}
Gå ind i det dokument, sheet eller andet, du gerne vil dele.
{% endstep %}

{% step %}
Tryk på <img src="../.gitbook/assets/image (19).png" alt="" data-size="line">.
{% endstep %}

{% step %}
Vælg <img src="../.gitbook/assets/image (20).png" alt="" data-size="line">.
{% endstep %}

{% step %}
Vælg <img src="../.gitbook/assets/image (21).png" alt="" data-size="line">.
{% endstep %}

{% step %}
Der kommer nu et vindue frem, hvor du kan ændre delingsindstillingerne.
{% endstep %}

{% step %}
Under **Generel adgang** skal du trykke på **Begrænset** og vælge **Alle med linket**.

<figure><img src="../.gitbook/assets/image (65).png" alt="" width="375"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Som standard vælger Google, at dem du deler med kun kan **læse** dokumentet. Det betyder, at de ikke kan redigere i dokumentet.

<figure><img src="../.gitbook/assets/image (66).png" alt="" width="375"><figcaption></figcaption></figure>
{% endstep %}

{% step %}
Hvis de skal kunne redigere, skal du vælge **Redaktør** i stedet for **Læser**.
{% endstep %}

{% step %}
Vælg om modtageren skal have **Læser**- eller **Redaktør**-adgang.
{% endstep %}

{% step %}
Tryk på <img src="../.gitbook/assets/gdrive-share-button-01.png" alt="" data-size="line"> for at kopiere det link, som du kan dele.
{% endstep %}

{% step %}
Linket kan fx se således ud:

`https://docs.google.com/document/d/1e8MkOkBruYUsXxxXxxXDTUTXXXxzr3qlxMXxxbc/edit?usp=sharing`
{% endstep %}

{% step %}
Send linket til dem, du gerne vil dele dokumentet med.
{% endstep %}
{% endstepper %}

## Hvis det ikke virker

{% expandable title="Modtageren kan ikke åbne linket" %}
Tjek at **Generel adgang** er ændret fra **Begrænset** til **Alle med linket**, og at du har sendt det kopierede link.
{% endexpandable %}

{% expandable title="Modtageren kan ikke redigere" %}
Tjek at rollen er sat til **Redaktør** og ikke kun **Læser**.
{% endexpandable %}
