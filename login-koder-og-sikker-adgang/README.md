# Login, koder og sikker adgang

Her finder du de guides, du skal bruge, når noget handler om adgang: @meddel.dk-login, elevkoder, din egen kode og OS2faktor.

{% hint style="warning" %}
For medarbejdere er @meddel.dk-kontoen normalt den rigtige vej ind til Aula og undervisningsportaler — også når knappen hedder “Unilogin”.
{% endhint %}
